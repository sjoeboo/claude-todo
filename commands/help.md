# TODO Help

```
📋 TODO Commands (GitHub Issues)
════════════════════════════════════════════

/todo add <task>       Create a new issue
/todo list             Show open issues
/todo complete <N>     Close issue #N
/todo start <N>        Move to In Progress
/todo block <N>        Move to Blocked
/todo unblock <N>      Move to In Progress

────────────────────────────────────────────

Natural language also works:
  "add a todo for X"
  "mark #5 as done"
  "what are my todos"
  "start working on #3"
```
